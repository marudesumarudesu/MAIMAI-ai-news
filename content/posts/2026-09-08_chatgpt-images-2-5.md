# ChatGPT Images 2.5公開｜最大50%高速化、Sketch・部分編集・API 2モデル追加。価格はGPT-Image-2の2倍

## 3行でいうと

- OpenAIは2026年9月8日、画像生成モデル「ChatGPT Images 2.5」を公開しました。Images 2.0比で**生成レイテンシを最大50%削減**し、人物やペットなど参照画像の特徴保持、部分編集、複数回編集の一貫性を改善しています。
- ChatGPTには**Sketch、Templates、画像上のコメント編集、プロンプト共有**を追加。ChatGPT、ChatGPT Work、Codexの全ティアでデスクトップ・モバイル・Webへ順次展開されています。
- APIには`gpt-image-2.5-flare`と`gpt-image-2.5-sunburst`を追加。ただし公式価格では、画像入力・画像出力・テキスト入力の単価が**GPT-Image-2の2倍**です。高速化だけを見て自動移行すると、生成量の多いサービスではコストが増える可能性があります。

## 何が発表された？

OpenAIは9月8日、ChatGPT Images 2.5と、開発者向けの2つの新しい画像APIモデルを発表しました。

OpenAIによると、ChatGPT ImagesとAPIのGPT-Imageモデルでは現在、**週30億枚超**の画像が生成されています。今回の2.5では、画像生成そのものの品質に加え、「一度作った画像を壊さずに修正する」能力が重点的に強化されています。

主な変更は次の通りです。

| 項目 | ChatGPT Images 2.5 |
|---|---|
| 発表日 | 2026年9月8日 |
| ChatGPT提供対象 | ChatGPT / ChatGPT Work / Codex |
| プラン | 全ティア |
| 対応環境 | Desktop / Mobile / Web |
| Images 2.0比レイテンシ | 最大50%削減 |
| 新UI | Sketch / Templates / コメント編集 / Prompt共有 |
| APIモデル | GPT-Image-2.5 Flare / Sunburst |
| 安全対策 | C2PA metadata、invisible watermarking、prompt/image checks |

OpenAIが改善点として挙げているのは、より自然な照明、豊かな質感、参照画像の被写体保持、編集指示への追従、複数ターン編集の一貫性です。

「複数ターン編集」とは、一度画像を生成したあと、「背景だけ変更」「商品ロゴを追加」「人物は変えず服だけ変更」のように修正を積み重ねる使い方です。

従来の画像生成では、一部分だけ変更したいのに顔、構図、商品形状まで変わることがありました。2.5は、変更対象以外を保持する性能を改善したとOpenAIは説明しています。

## 今までと何が違う？

### ChatGPT側

| 機能 | Images 2.0 | Images 2.5 |
|---|---|---|
| 生成速度 | 基準 | 最大50%低レイテンシ |
| 参照人物・ペットの保持 | 対応 | 特徴保持を改善 |
| 部分編集 | 対応 | 指定箇所以外の保持を改善 |
| 複数回編集 | 崩れる場合あり | 一貫性を改善 |
| 手描き入力 | 標準機能としてなし | Sketch追加 |
| テンプレート | 限定的 | Poster、Merch等から開始可能 |
| 画像へのコメント指示 | なし | 対応 |
| Prompt共有 | 限定的 | 画像共有時にPromptも共有可能 |

特にSketchは初心者への影響が大きい機能です。

モバイルではメッセージ欄で`@`からSketchを選択し、指やペンでラフを描いてから文章で仕上がりを指定できます。

例えば「画像の右下に商品を置きたい」と長文で位置関係を説明する代わりに、四角を描いて場所を示せます。

### API側

APIでは用途を分けた2モデルが追加されました。

| モデル | 向いている用途 | 特徴 |
|---|---|---|
| `gpt-image-2.5-flare` | SNS画像、EC、Visual Search、試作、大量生成 | OpenAI推奨の標準選択。GPT-Image-2より高品質、50%低レイテンシ |
| `gpt-image-2.5-sunburst` | 広告クリエイティブ、商品画像、精密編集 | 編集精度を優先。Flareより生成時間が長い |

OpenAIの顧客事例では、ManusがFlareについて「GPT-Image-2の2〜4倍の速度」と評価しています。ただし、これはManus環境での評価であり、すべてのAPI利用で2〜4倍になる保証値ではありません。

## 価格はどう変わった？

公式API価格を確認すると、2.5系はGPT-Image-2より単価が上がっています。

価格は100万トークンあたりです。

| モデル | Text input | Image input | Cached image input | Image output |
|---|---:|---:|---:|---:|
| GPT-Image-2 | $2.50 | $4.00 | $1.00 | $15.00 |
| GPT-Image-2.5 Flare | $5.00 | $8.00 | $2.00 | $30.00 |
| GPT-Image-2.5 Sunburst | $5.00 | $8.00 | $2.00 | $30.00 |

つまり、公式のトークン単価では2.5のFlareとSunburstは**GPT-Image-2の2倍**です。

ここは「50%高速化」と分けて見る必要があります。

レイテンシが半減しても、課金単位であるトークン消費量が同じなら料金は上がります。企業が大量生成へ使う場合は、速度だけでなく**1枚当たりの実請求額**を既存モデルと比較する必要があります。

FlareとSunburstの単価は同じなので、選択基準は速度と編集精度です。

## これで何ができる？

### 1. 商品写真の一部分だけ変更する

EC企業なら、同じ商品の写真を使って、

> 商品本体、ロゴ、カメラ位置は一切変更せず、背景だけを白いスタジオ背景にしてください。

と編集できます。

2.5では指定していない商品や構図を保持する性能が改善されています。

商品ページごとに撮影し直す代わりに、背景や季節演出のバリエーションを生成する用途と相性があります。

### 2. 手描きから広告やSNS画像を作る

Sketchで、

- 左側に人物
- 右上に商品
- 下部にタイトル

という大まかな配置を描き、

> このレイアウトを維持して、春の新商品キャンペーン用の広告にしてください。商品は添付写真を使用し、人物より商品を目立たせてください。

と指示できます。

文章だけで位置関係を指定する負担が減ります。

### 3. 同じ人物を使った複数クリエイティブを作る

参照写真を入れて、

> 人物の顔、髪型、体型は維持。服だけネイビーのジャケットに変更。

その後、

> 人物はそのまま。背景だけオフィスからカフェへ変更。

と段階的に編集できます。

インフルエンサー素材、社員プロフィール、広告バリエーションなどで、人物の一貫性が重要なケースに向きます。

### 4. APIで大量のEC画像を生成する

大量生成ではFlareが基本候補です。

商品DBの情報から、

- 白背景商品画像
- SNS用比率
- 季節キャンペーン
- 広告バナー

を自動生成するシステムに組み込めます。

一方、最終納品用の広告やブランドガイドに沿った細かい修正ではSunburstを使う、という分離が考えられます。

## 誰に関係ある？

### 個人

影響は大きいです。

画像生成に慣れていない人でも、Sketchやコメントで「どこを変えたいか」を視覚的に伝えられます。

ChatGPTの全ティア対象なので、特定の有料プランだけに限定された機能ではありません。ただし、利用回数などの上限は各プランの制限に従います。

### 企業

広告、EC、SNS運用、デザイン、メディア、商品企画を持つ企業には重要です。

特に改善効果が期待できるのは「ゼロから1枚作る」工程より、既存素材から多数の派生クリエイティブを作る工程です。

### 開発者

API利用者はモデル選択が増えます。

高速・大量処理はFlare、精密編集はSunburstという使い分けが基本です。

ただし、旧GPT-Image-2から単純にモデルIDだけ変更する前に費用試算が必要です。

### 日本ユーザー

OpenAIはImages 2.5を全ティア・Desktop / Mobile / Webへ展開すると発表しており、日本を除外する地域制限は今回の発表では示していません。

日本のImpress Watch、マイナビニュースでも9月9日に提供開始が報じられています。

## 実際の使い方

### Sketch

モバイル版ChatGPTで、

1. メッセージ入力欄の`@`をタップ
2. `Sketch`を選択
3. ラフを描く
4. 描画後に完成イメージを文章で指示
5. 生成後はコメントや通常の文章で修正

という流れです。

例えば、

> 青い四角は商品写真、赤い線は見出し位置です。構図を維持し、1280×670のビジネス向け見出し画像として仕上げてください。

のように使えます。

### 部分編集

生成済み画像を全画面で開き、変更したい位置にコメントを付けます。

> この部分だけ文字を「AI活用入門」に変更。他の文字、人物、背景、配色、構図は変更しない。

変更禁止事項まで書くと、狙った部分だけ編集する意図が明確になります。

### API

大量生成なら`gpt-image-2.5-flare`、精密編集なら`gpt-image-2.5-sunburst`をモデルとして選択します。

OpenAIはFlareを大半のアプリケーションの標準選択として位置づけています。

## 注意点

### APIは旧モデルより単価が高い

最も重要な注意点です。

Flareが50%低レイテンシでも、公式トークン単価はGPT-Image-2の2倍です。

高速化とコスト削減を同じ意味で扱わない方がよいです。

### Sunburstは高速モデルではない

Sunburstは詳細編集の制御性を優先したモデルで、OpenAI自身がFlareより長い生成時間を明記しています。

大量のSNS画像をSunburstへ統一すると、必要以上に待ち時間が増える場合があります。

### 参照画像を使っても完全一致は保証されない

OpenAIは人物・被写体の保持改善を説明していますが、写真編集ソフトのレイヤー編集と同じ意味ではありません。

顔、商品形状、文字、ロゴなど、絶対に変更してはいけない要素は生成後に人間が確認する必要があります。

### 著作権・肖像権は別問題

技術的に人物や既存画像を編集できても、その画像を商用利用してよいかは権利関係で決まります。

他人の写真、キャラクター、ブランド素材を扱う場合は利用許諾を確認する必要があります。

### AI生成画像の識別情報は継続

OpenAIはImages 2.5でもC2PA metadataとinvisible watermarkingを利用すると説明しています。

ただし、これだけですべての二次加工後画像を確実に識別できるとOpenAIは説明していません。
