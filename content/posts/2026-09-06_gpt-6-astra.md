# GPT-6 Astra登場｜1.05Mコンテキスト、API $10/$50、Plus以上へ段階展開。何が本当に変わった？

## 3行でいうと

- OpenAIは2026年9月3日、**GPT-6 Astra**を発表。コーディング、調査、PC操作、文書作成を「途中工程ごと」ではなく、完成まで長く進める能力を前面に出しています。
- APIは**1,050,000トークンのコンテキスト、最大128,000トークン出力、入力$10/100万token・出力$50/100万token**。GPT-5.6 Solと同じ巨大コンテキストですが、価格は2.5倍です。
- ChatGPTではPlus、Pro、Business、Enterpriseへ段階展開。性能だけを見るモデルではなく、**高い単価を払ってでも複雑な仕事を一気通貫で任せる価値があるか**が判断ポイントです。

## 何が発表された？

OpenAIは9月3日、GPT-6 Astraを「最も難しいend-to-end work向け」のモデルとして公開しました。

end-to-end workとは、例えば「資料を読んで」「分析して」「表を作って」「PowerPointへまとめて」のように、人間が工程を細かく分けず、最初の依頼から完成物まで進める仕事です。

公式API仕様では次の数字が確認できます。

| 項目 | GPT-6 Astra |
|---|---:|
| コンテキスト長 | 1,050,000 tokens |
| 最大出力 | 128,000 tokens |
| knowledge cutoff | 2026-04-30 |
| API入力 | $10 / 100万tokens |
| cached input | $1 / 100万tokens |
| API出力 | $50 / 100万tokens |
| reasoning effort | low / medium / high / xhigh / max |
| fine-tuning | 非対応 |

Web検索、File search、Image generation、Code interpreter、Hosted shell、Computer use、MCPなどのツールにも対応します。

## 今までと何が違う？

比較対象としてGPT-5.6 Solを見ると違いが分かりやすいです。

| 項目 | GPT-5.6 Sol | GPT-6 Astra |
|---|---:|---:|
| コンテキスト | 1.05M | 1.05M |
| 最大出力 | 128K | 128K |
| 入力価格 | $4 / 1M | $10 / 1M |
| 出力価格 | $20 / 1M | $50 / 1M |
| 主な位置づけ | 複雑な専門仕事 | 最難関のend-to-end work |

つまり「読める量が増えたモデル」ではありません。同じ大容量コンテキストを使いながら、長時間のツール利用、PC操作、研究、コード、成果物作成までを高い精度でつなぐ方向へ性能を上げています。

OpenAIはARC-AGI-3、FrontierMath Tier 4、ExploitBenchなどで非常に高いスコアを公表しています。ただしベンチマークは実務の成功率そのものではありません。例えばARC-AGI系は未知のパターンからルールを見抜く能力を見る評価であり、「あなたのExcelが必ず正しく分析できる」という意味ではありません。

## これで何ができる？

### 1. 調査から経営資料までまとめて作る

複数の公式情報を調べ、競合比較を行い、Excel形式の表を作り、その内容をPowerPointへまとめる、といった複数工程をまとめて渡す用途です。

### 2. 大規模コードベースの修正

リポジトリを調査し、バグ原因を探し、複数ファイルを修正し、テストまで実行する長時間タスクに向きます。

### 3. PC操作を含む業務

ブラウザやコンピューター操作ツールを組み合わせ、情報収集から入力作業まで進めるエージェント用途が中心です。

## 誰に関係ある？

**個人ユーザー**：Plus以上で段階的に利用可能になりますが、日常の文章・軽い検索だけならAstraが必要とは限りません。

**企業**：複数アプリをまたぐ知識労働や資料作成、社内エージェントを設計している企業には重要です。

**開発者**：API単価はSolの2.5倍なので、全処理をAstraへ切り替えるより「失敗コストが高い難タスクだけAstra」というルーティングが現実的です。

**日本ユーザー**：ChatGPTの日本語利用でも恩恵はありますが、段階展開なのでアカウントごとに提供時期がずれる可能性があります。

## 実際の使い方

ChatGPTで利用可能になったら、細かく指示を分けるより完成条件まで渡す方がAstraの特徴を試せます。

例：

「添付した3社の決算資料を読み、売上成長率・営業利益率・会社計画を比較してください。差が出た要因を一次資料の該当箇所と一緒に整理し、最後に経営会議向け5枚のスライド構成を作ってください。不明な数字は推測しないでください。」

API利用ではモデルID `gpt-6-astra` を指定します。ツールを本格利用する場合、OpenAIはResponses APIを推奨しています。

## 注意点

Astraは高性能ですが、API価格も高いです。特に長大な入力が272K tokensを超える場合、公式仕様では入力・キャッシュ料金が2倍、出力料金が1.5倍になるため、大量文書を毎回丸ごと送る設計はコストが膨らみます。

またAstraはサイバー能力がOpenAIのPreparedness FrameworkでCritical水準に達した初のモデルとされています。このため、安全監視や一部のエージェント処理停止など、通常モデルより強いガードレールがあります。
