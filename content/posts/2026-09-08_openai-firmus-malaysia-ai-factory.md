# OpenAIがマレーシア2拠点でAI計算能力を確保｜Firmusと複数年契約、Vera Rubin NVL72採用でアジア太平洋のAI基盤が拡大

## 3行でいうと

- OpenAIと豪AIインフラ企業Firmusは2026年9月8日、**マレーシアの2つのAI Factoryから専用AI計算能力を提供する複数年契約**を発表しました。OpenAIは両拠点のアンカーカスタマーになります。
- Firmusの全顧客向け契約済み容量は今回の契約を含め**900MW超**。同社はオーストラリア、シンガポール、インドネシア、マレーシアで計7拠点を展開し、現在2拠点が稼働、5拠点を今後24か月以内のサービス開始に向けて建設しています。
- マレーシア拠点には**NVIDIA Vera Rubin NVL72**を採用予定です。OpenAIがアジア太平洋で生成AIを提供するための計算基盤を増やす動きであり、日本ユーザーにとっても将来の地域内キャパシティやサービス供給余力を見るうえで重要です。ただし、日本向けの遅延改善や価格低下は現時点で発表されていません。

## 何が発表された？

Firmusは2026年9月8日、OpenAIとの複数年にわたる戦略的パートナーシップを発表しました。

契約内容は、Firmusがマレーシアで開発する**2つのAI FactoryサイトからOpenAI向けに専用のAI計算能力を提供する**というものです。

OpenAIはこの2拠点のアンカーカスタマーになります。アンカーカスタマーとは、大規模施設の立ち上げ時に一定量の利用を長期契約し、事業計画を支える主要顧客です。

契約金額、OpenAIが確保する正確なMW数、具体的なサービス開始日は公表されていません。

Firmus全体では、今回のOpenAI契約を含む全顧客向けの契約済み容量が**900MWを超えた**としています。

| 項目 | 2026年9月8日時点 |
|---|---:|
| 対象国 | オーストラリア、シンガポール、インドネシア、マレーシア |
| AI Factory総数 | 7拠点 |
| 稼働中 | 2拠点 |
| 開発中 | 5拠点 |
| 開発中拠点の目標 | 今後24か月以内にサービス開始 |
| 全顧客の契約済み容量 | 900MW超 |
| OpenAI向け | マレーシア2拠点の専用AI計算能力 |

OpenAIのVP of Compute StrategyであるSachin Katti氏は、Firmusの発表内で、マレーシアの新しいデータセンターがアジア太平洋地域と世界で増えるOpenAI製品の需要に対応する助けになると説明しています。

Reutersも9月8日にこの契約を報じ、FirmusがNVIDIA、Jane Street、Blackstone系ファンド、Coatueなどから出資を受けていること、マレーシアが東南アジアで急成長するデータセンター市場になっていることを伝えています。

## 今までと何が違う？

今回のニュースには新しいChatGPT機能や新モデルはありません。

変わったのは、**OpenAIがアジア太平洋で利用できる大規模計算基盤をさらに確保したこと**です。

生成AIサービスでは、モデルの性能だけでは供給能力は決まりません。推論用GPU、電力、冷却設備、ネットワーク、データセンター容量が足りなければ、ユーザー数やエージェント利用量が増えたときに処理能力が不足します。

Firmusは、マレーシアを含むAI FactoryでNVIDIAの次世代**Vera Rubin NVL72**を大規模展開する計画です。

NVIDIA公式仕様では、Vera Rubin NVL72は以下の構成です。

| 項目 | Vera Rubin NVL72 |
|---|---:|
| Rubin GPU | 72基 |
| Vera CPU | 36基 |
| GPUメモリ | 合計20.7TB HBM4 |
| GPUメモリ帯域 | 最大1,580TB/s |
| NVFP4推論性能 | 3,600 PFLOPS |
| NVFP4学習性能 | 2,520 PFLOPS |
| NVLink | 第6世代 |

NVIDIAはRubin世代について、Blackwell世代と比較してMoEモデルの学習に必要なGPU数を4分の1にし、AI推論では最大10倍低いトークン当たりコストを目標値として説明しています。

これはNVIDIA自身のプラットフォーム評価であり、OpenAIの実際のChatGPT運用コストが10分の1になるという意味ではありません。

## これで何ができる？

### 1. ChatGPT・APIの利用増加に対応する計算余力を増やす

OpenAIではChatGPTだけでなく、API、Codex、AIエージェントなど、長時間GPUを使うサービスが増えています。

アジア太平洋に計算基盤を追加することで、将来の需要増に対応できる物理的な余力が増えます。

### 2. より計算量の大きいモデルやエージェントを運用する基盤になる

Vera Rubin NVL72は、大規模なMoEモデル、長いコンテキスト、エージェント型推論を想定したラックスケールシステムです。

OpenAIが今後、1回の回答で複数工程を実行するモデルを増やす場合、こうしたインフラの確保が前提になります。

### 3. アジア太平洋の企業需要を地域内で支える余地が増える

OpenAIは今回の契約について、アジア太平洋地域の需要への対応を明示しています。

日本企業がOpenAI APIを大量利用するケースでも、世界全体の計算能力が増えることは供給面でプラスです。

ただし、今回の発表には「日本企業の処理を必ずマレーシア拠点で実行する」「日本からの通信遅延が何ms減る」といった説明はありません。

## 誰に関係ある？

### 個人ユーザー

すぐにChatGPTの画面や料金が変わるニュースではありません。

個人ユーザーへの影響は間接的です。利用者が増え、動画・音声・エージェント処理が増えるほど、OpenAIには大量の計算能力が必要になります。

### 企業

OpenAI APIを大量に使う企業には重要です。

特に、AIエージェントを常時実行する、大量文書を処理する、コーディングエージェントを開発部門へ展開する、音声・画像・動画を扱う、数千〜数万ユーザー規模でAIを利用する企業では、モデル性能と同時に供給能力・障害耐性・地域インフラも重要になります。

### 開発者

今回の契約によってAPI名やSDKの使い方が変わることは発表されていません。

そのため、開発者がコードを変更する必要はありません。

### 日本ユーザー

日本にとっての意味は、OpenAIがアジア太平洋の計算能力を増強している点です。

ただし、日本リージョン新設、日本国内データ保管、データレジデンシー変更、API価格変更は今回発表されていません。

日本企業は今回のニュースだけを根拠に「データがマレーシアに保存される」「日本から高速になる」と判断しない方がよいです。

## 実際の使い方

今回の発表はインフラ契約なので、利用者が有効化する設定や新しいプロンプトはありません。

OpenAI APIを利用している企業が確認すべきなのは、自社側の運用指標です。

例えば、1日当たりAPIリクエスト数、ピーク時間帯のレイテンシ、429エラーなどのレート制限、1業務あたりの推論トークン、エージェント1件あたりの完了時間、障害時の代替モデルを記録します。

大規模AI導入では「モデルが賢いか」だけでなく、必要な時間に必要な計算量を安定して確保できるかを見た方が実務的です。

## 注意点

### OpenAIが900MWを契約したわけではない

900MW超は**Firmusが全顧客から契約している合計容量**です。

OpenAI単独の契約容量は公表されていません。

### 契約金額は非公表

Reutersによると、Firmusは契約金額へのコメントを控えています。

金額を推測して事業規模を断定することはできません。

### 5拠点はまだ稼働していない

Firmusの7拠点のうち、現在稼働しているのはオーストラリアとシンガポールの2拠点です。

残り5拠点は開発中で、今後24か月以内のready-for-serviceを目標としています。

### 電力・水資源の問題

Reutersは、マレーシアのデータセンター急増に伴い、電力と水使用への監視が強まっている点も指摘しています。

AI Factoryの拡張にはGPU確保だけでなく、電力網、冷却、水、送電設備、建設許認可が必要です。

### 日本向けサービス改善は未発表

今回の契約から、日本のChatGPT価格、API価格、データレジデンシー、遅延が変わるとは確認できません。

## MAIMAIの評価

**重要度：88 / 100**

### 一般ユーザー：72点

画面上の新機能ではないため即効性は低めです。

一方、生成AIがチャットから長時間稼働するエージェントへ移るほど、計算基盤の確保はサービス品質に影響します。

### 企業：91点

企業利用では重要です。

生成AI導入が数十人規模から全社利用へ進むと、コストと供給能力が現実的な制約になります。

OpenAIがアジア太平洋で専用計算能力を長期確保することは、地域需要の増加を前提にした投資と評価できます。

### 日本市場：87点

日本はマレーシアと同じアジア太平洋地域にあります。

将来的な地域キャパシティ拡大という意味ではプラスですが、日本国内リージョンやデータ保管条件については別問題です。

日本企業は「近い地域にAI Factoryができること」と「自社データがどこで処理・保存されるか」を分けて評価する必要があります。

### 競争環境：94点

主要AI企業の競争は、モデル性能と同時に**電力・GPU・データセンターをどれだけ長期確保できるか**に広がっています。

Google、Microsoft、Meta、xAIなども大規模AIインフラへ投資しており、最先端モデルを継続提供するには数年先の電力と半導体を先に押さえる必要があります。

MAIMAIとしては、今回の契約を2027〜2028年のモデル・エージェント需要を支える供給網の先行投資として評価します。
